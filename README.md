# QuotaPeek

独立 Windows x64 额度工具。此仓库只用于分发安装包、更新说明及第三方许可证，不包含 QuotaPeek 应用源码或任何账号凭据。

## 下载与安装

打开本仓库的 **Releases → Latest**，下载 `QuotaPeek-Setup-版本号.exe` 并安装。

- 无需安装 Python、Git、Node.js、Codex 或 Hermes；新电脑需要自行登录。
- Codex 显示已授权账号的短期和每周额度；WorkBuddy 需要本机已有兼容桥接，不会自动安装桥接。
- 任务栏额度条依赖兼容的 Windows 11 Explorer 布局；不兼容时可用托盘和主看板。
- 当前安装包未进行代码签名，Windows 可能提示未知发布者。请核对下载来源，不要关闭系统安全防护。

## 更新

在 QuotaPeek 的「设置 → 关于」或托盘菜单点击 **检查更新**。确认下载后，程序会校验安装包的大小与 SHA-256 并打开所在文件夹。

请优先安装 **1.0.1 或更高版本**。1.0.0 在需要代理访问 GitHub 的网络中可能检查超时，请手动下载新版覆盖安装。1.0.1 起沿用已有系统／环境代理，不修改全局设置；所有更新仍要求当前网络能够访问 GitHub。

**先从托盘退出 QuotaPeek，再双击新安装包覆盖安装。** 不会静默安装、强行结束程序或自动同步源码。

账号和设置位于当前用户的 `%LOCALAPPDATA%\AIQuotaDesktop`，授权凭据由 Windows 凭据管理器保存。升级和卸载均不主动清理这些数据，卸载不等于注销账号。

`update-manifest.json` 是软件读取的更新清单，不是用户需要手动运行的文件。哈希用于下载完整性检查，不等于发布者的代码签名。
